### Open source

- **[Supaco](https://github.com/kellyson71/supaco)**: toolkit for IFRN's academic system (SUAP) with an Android app (Kotlin, Jetpack Compose), a Go CLI, a React web dashboard and a Python library. [Website](https://kellyson71.github.io/supaco/)
- **[SuaPy](https://github.com/kellyson71/suapy)**: Python library on [PyPI](https://pypi.org/project/suapy/) for grades, absences and schedules from the SUAP API.
- **[hypr-shell-switcher](https://github.com/kellyson71/hypr-shell-switcher)**: switches between Quickshell shells on Hyprland without restarting the session.
- **[Pytomba](https://github.com/kellyson71/pytomba)**: educational programming language in Portuguese, translated to Python through Python's own tokenizer.
- **[php-deploy-guard](https://github.com/kellyson71/php-deploy-guard)**: blocks SSH/FTP deploys to the wrong project and monitors site uptime.
