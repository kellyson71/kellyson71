### Open source

- **[Supaco](https://github.com/kellyson71/supaco)**: ecossistema para o SUAP do IFRN com app Android (Kotlin, Jetpack Compose), CLI em Go, painel web em React e biblioteca Python. [Site](https://kellyson71.github.io/supaco/)
- **[SuaPy](https://github.com/kellyson71/suapy)**: biblioteca Python publicada no [PyPI](https://pypi.org/project/suapy/) para consultar boletim, faltas e horários na API do SUAP.
- **[hypr-shell-switcher](https://github.com/kellyson71/hypr-shell-switcher)**: troca entre shells Quickshell no Hyprland sem reiniciar a sessão.
- **[Pytomba](https://github.com/kellyson71/pytomba)**: linguagem educativa em português, traduzida para Python pelo próprio tokenizador da linguagem.
- **[php-deploy-guard](https://github.com/kellyson71/php-deploy-guard)**: impede deploy SSH/FTP no projeto errado e monitora o uptime dos sites.
