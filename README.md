Estudante de **Análise e Desenvolvimento de Sistemas** no IFRN – Pau dos Ferros. Bolsista no **NADIC** (Núcleo de Análise de Dados e Inteligência Computacional).

Trabalho com desenvolvimento e manutenção de sistemas usados por órgãos públicos municipais — gestão de estágios, tramitação administrativa, licenciamento ambiental e controle de trânsito. Experiência com PHP legado, ambientes de hospedagem compartilhada e fluxos multi-setor em produção.

Autor da [**Suapy**](https://pypi.org/project/suapy/), biblioteca Python para integração com a API do SUAP, publicada no PyPI.

Atualmente desenvolvendo aplicações desktop com **Electron + React + TypeScript**.

## 🐍 Suapy

[![PyPI version](https://img.shields.io/pypi/v/suapy?style=flat-square)](https://pypi.org/project/suapy/)
[![PyPI downloads](https://img.shields.io/pypi/dm/suapy?style=flat-square)](https://pypi.org/project/suapy/)

Biblioteca Python para integração com a API do SUAP. Documentação em português, publicada no PyPI.

```python
from suapy import Suapy

suap = Suapy(username="matricula", password="senha")
dados = suap.get_dados_pessoais()
```
